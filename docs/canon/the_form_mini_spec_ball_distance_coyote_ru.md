# The Form — Mini Spec: Ball Distance Coyote

## Назначение

Сделать прыжок мяча предсказуемым и классически читаемым, убрав чрезмерно дальний coyote и неверное поведение около поверхностей.

## Контракт

- `Ball` получает право на обычный jump не только по времени после потери контакта, но и по расстоянию до ближайшей валидной поверхности.
- Приоритет у `distance-based coyote`, а не у старого чисто временного окна.
- Wall impact не должен сохранять запрещённый jump intent/impulse.
- Rebound logic и обычный jump не должны конфликтовать.

## Дефолтные допущения

- Расстояние считается от ближайшей точки коллайдера мяча до ближайшей валидной поверхности.
- В первой версии distance coyote действует только на обычный jump.
- Для special state с удержанным `K` допускается отдельный параметр позже, но базовая архитектура должна это позволять.
- Если нет надёжного distance query в первом проходе, временно допустим гибрид: time gate + distance gate, но итоговая логика должна быть distance-led.

## Acceptance Criteria

- Игрок не может прыгать слишком далеко после ухода с края.
- Игрок может прыгнуть в ожидаемом малом зазоре рядом с поверхностью.
- Удар о стену больше не оставляет неправильный jump impulse.
- Rebound не ломает обычный jump flow.

## Риски

- Слишком агрессивный distance coyote убьёт feel.
- Слишком мягкий distance coyote вернёт старую проблему.
- Если смешать jump и rebound eligibility в одну кучу, поведение станет нечитаемым.

## Что потом можно уточнить

- отдельный coyote для `K` state;
- отдельный coyote для floor/wall/ceiling;
- точный debug visualization distance probe.
