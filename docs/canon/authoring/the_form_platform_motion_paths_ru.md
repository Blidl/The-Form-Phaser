# The Form - Platform Motion Paths (RU)

## Цель
Движущиеся платформы должны использовать motion paths и motion states, а не только схему `axis + travelDistance`.

## Ограничения demo
- В demo путь платформ задается только прямыми polyline-точками.
- Bezier/CatmullRom для demo не используются.

## Переиспользуемость
- Motion paths должны быть переиспользуемы для платформ.
- В дальнейшем тот же механизм может применяться и к другим акторам.

## Валидация
Обязательна проверка:
- корректности ссылок на path;
- валидности точек (структура, количество, допустимые значения);
- соответствия motion state выбранному path-контракту.
