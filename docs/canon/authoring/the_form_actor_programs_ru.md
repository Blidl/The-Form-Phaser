# The Form - Actor Programs (RU)

## Назначение
Actor Programs - это переиспользуемые authorable-программы для акторов, формирующие единый исполняемый слой поверх разных систем authoring.

## Поддерживаемые типы узлов
- `sequence`
- `parallel`
- `action`
- `wait`
- `if`
- `loop`
- `emit_event`

## Модель выполнения
- Программы могут исполняться в очередях.
- Очереди должны поддерживать управляемый запуск, остановку и переходы между программами.
- Должна поддерживаться параллельность действий внутри программы.

## Обязательные требования
- Явная политика cancellation/ownership.
- Валидация структуры программ, ссылок и типов узлов.
- Debug recording исполнения (временные метки, переходы, причины остановки/отмены).

## Архитектурные границы
- Actor Programs не заменяют NPC Behavior Pages.
- Actor Programs не заменяют Director Timeline.
- Actor Programs - это общий исполняемый слой, который может вызываться из разных систем.

## Миграция
Legacy сценарии могут жить параллельно и подключаться через адаптеры, пока не подтверждена полная совместимость нового потока authoring.
