# The Form - Actor Control Ownership (RU)

## Цель
Зафиксировать явные правила владения управлением актором, чтобы исключить конкуренцию систем за один и тот же объект.

## Источники управления
Источники control ownership могут включать:
- ввод игрока;
- NPC behavior;
- actor program;
- director timeline;
- replay/freeze state.

## Базовые принципы
- Правила ownership должны быть явными и проверяемыми.
- Недопустимы неявные конфликты, когда несколько систем одновременно управляют движением/боем одного актора.
- Перед запуском исполняющего шага должна быть проверена валидность текущего владельца управления.

## Параллельные слои
- Manpu и Focus Marker являются overlay-слоями.
- Overlay-слои могут работать параллельно с movement/combat, если это не нарушает явные ownership-правила.

## Валидация
- Конфликтующие назначения ownership должны ловиться в Validation Service.
- Переход владения между системами должен оставлять debug-след для диагностики.
