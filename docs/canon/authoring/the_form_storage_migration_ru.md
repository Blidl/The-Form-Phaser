# The Form - Storage и Migration (RU)

## Источник истины
- Канонический source of truth: JSON-файлы проекта.
- `localStorage` только для autosave/crash recovery.

## Правила localStorage
- `localStorage` никогда не должен молча переопределять bundled JSON.
- Autosave/drafts должны быть явно показаны пользователю как drafts.

## Миграционная стратегия
- Старые инструменты мигрируются постепенно через адаптеры/миграции.
- Legacy системы не удаляются до подтвержденной валидации нового слоя.
- Миграция старых данных выполняется явными шагами миграции с обязательной валидацией.

## Практика внедрения
- Каждый миграционный шаг должен быть обратимым или безопасно повторяемым.
- На каждом этапе фиксируются совместимость форматов и результаты проверок.
