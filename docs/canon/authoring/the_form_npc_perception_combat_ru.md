# The Form - NPC Perception и Combat (RU)

## Perception-модель
NPC perception поддерживает:
- радиус;
- угол;
- line-of-sight.

## Debug и визуализация
- Для perception обязательна debug-визуализация.
- Визуализация должна помогать проверять геометрию восприятия, цели и причины срабатывания/несрабатывания.

## Архитектурный принцип
- Perception/combat должны быть переиспользуемыми runtime slices.
- Логика perception/combat не должна быть editor-специфичной.

## Поведенческие возможности NPC
Согласно authored данным NPC может:
- атаковать;
- получать урон/быть атакованным;
- умирать;
- респавниться;
- толкать;
- блокировать;
- взаимодействовать с другими NPC.

## Обязательная валидация
Validation Service должен проверять:
- ссылки на акторов;
- команды/фракции (если вводятся позже);
- perception targets;
- ссылки на combat actions.
