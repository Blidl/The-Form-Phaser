## Правило использования
- Если ответ внешнего чата длинный, не копировать весь диалог.
- Сначала заполнить этот шаблон.
- Потом при необходимости приложить raw ответ ниже отдельным блоком.

Это снижает риск запутаться между несколькими чатами и конфликтующими реализациями.
