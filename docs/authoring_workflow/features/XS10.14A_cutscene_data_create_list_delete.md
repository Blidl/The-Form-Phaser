# XS10.14A — Cutscene Data + Create/List/Delete UI

## Context
Current accepted state:
- NPC create/select/drag/delete works.
- NPC patrol/defaultAction works.
- trigger/onEnter can run scripts.
- start_cutscene command exists or is partially referenced.
- Full Cutscenes tab authoring is not implemented yet.

## Goal
Add minimal canonical cutscene data and Cutscenes tab UI so designers can create, list, select, edit basic settings, delete, save/export/import/reload cutscenes.

## Source spec
Cutscenes section requires:
- Cutscenes tab
- Interactive and Overlay subtabs
- list/search/create/delete cutscene
- selected cutscene settings
- name
- duration/time
- start condition
- actors list later
- camera actor by default later
- timeline later
Overlay is visible but can remain disabled for now.

## Scope
Implement only:
- canonical cutscene data in current level/runtime config
- Cutscenes tab or existing mode extension
- list cutscenes
- create interactive cutscene
- delete selected cutscene
- edit name
- edit durationMs
- type: interactive
- Overlay visible as disabled/deferred if easy
- save/export/import/reload persistence
- validation for duplicate/missing ids/basic shape

## Non-goals
- no runtime director
- no Play/Pause/Stop
- no NPC takeover
- no actor actions
- no timeline editor
- no overlay cutscenes
- no browser script editor
- no new command system
- no physics/collision changes

## Acceptance
1. Open Cutscenes tab.
2. Create Cutscene adds new cutscene with unique id and default name.
3. Select cutscene shows settings.
4. Edit name/duration.
5. Delete selected cutscene removes it.
6. Save Draft → Reload preserves cutscenes.
7. Export JSON contains cutscenes canonical data.
8. Import JSON restores cutscenes.
9. Existing NPC/platform/trigger systems still work.
10. npm run build-nolog passes.
11. npm run validate-authoring passes.
12. git diff --name-only -- src/game/authoring/editor_v2 is empty.
