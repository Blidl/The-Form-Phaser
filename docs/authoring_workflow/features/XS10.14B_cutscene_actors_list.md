# XS10.14B — Cutscene Actors List

## Context
XS10.14A added canonical cutscene data and Cutscenes tab create/list/select/edit/delete flow.

## Goal
Add cutscene actors list authoring.

## Scope
- Extend cutscene data with `actors[]`.
- Camera actor should exist by default for newly created interactive cutscenes.
- UI:
  - actors list for selected cutscene
  - add actor
  - remove actor
  - select actor
  - actor id/name
  - actor kind/type: camera | player | npc | object
  - target dropdown/list depending on actor type
- Persistence:
  - Save Draft / Export / Import / Reload preserve actors.
- Validation:
  - missing actor ids
  - duplicate actor ids inside cutscene
  - invalid actor type
  - missing target for npc/object/player where required
- No timeline/actions/playback yet.

## Non-goals
- no runtime cutscene director
- no Play/Pause/Stop
- no NPC takeover
- no actor action timeline
- no trigger launch yet
- no browser script editor
- no physics/collision changes

## Acceptance
1. Create cutscene.
2. Cutscene has default camera actor.
3. Add NPC actor and select target NPC from current level.
4. Add player actor.
5. Remove actor.
6. Save Draft → Reload preserves actors.
7. Export/Import preserves actors.
8. Validation catches invalid/missing actor refs.
9. `npm run build-nolog` passes.
10. `npm run validate-authoring` passes.
11. `git diff --name-only -- src/game/authoring/editor_v2` is empty.
