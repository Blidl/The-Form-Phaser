# XS10.11 — NPC Default Action Runtime

## Goal
NPC executes `behaviorScripts.defaultAction` when player presses I near that NPC.

## User Outcome
Designer assigns npc.action script in NPC inspector and tests it in gameplay.

## Current Accepted State
- NPC create/select/drag/delete works.
- NPC patrol behavior works.
- Legacy autonomous NPC behavior is disabled.
- NPC control mode foundation exists.
- NPC interactions are scoped per NPC instance.
- External scripts are file-based JSON assets.

## Scope
- Default Action assignment persists.
- Add demo npc.action script.
- Runtime execution on I/interact.
- Trace/status in NPC inspector.
- Support first-wave commands:
  - noop
  - set_world_flag
  - start_cutscene

## Non-Goals
- no cutscene takeover
- no visual config
- no npc.jump
- no browser script editing
- no generic ActionCommandRegistry rewrite
- no complex dialogue system
- no trigger/platform/level rewrites

## Acceptance
- Assign defaultAction to npc_1.
- Press I near npc_1 and assigned script runs.
- npc_2 without defaultAction does not run npc_1 action.
- If explicit npc/onInteract binding exists, precedence is clear and reported.
- Save Draft / Export JSON / Import JSON / Reload persist assignment.
- Export excludes runtime trace/control/debug state.
- npm run build-nolog passes.
- git diff --name-only -- src/game/authoring/editor_v2 is empty.
